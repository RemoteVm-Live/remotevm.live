## 🎥 معرفی پروژه

این پروژه یک ابزار حرفه‌ای و رایگان برای اتصال دوربین‌ها و منابع تصویری از راه دور است که از فناوری peer-to-peer برای انتقال مستقیم و امن صدا و تصویر استفاده می‌کند. کاربران می‌توانند با استفاده از آن، منابع ویدیویی خود را به صورت بی‌درنگ در نرم‌افزارهایی مانند OBS، VMix یا مرورگرهای پشتیبانی‌کننده از WebRTC ادغام کنند.

### برخی از ویژگی‌ها:

- 🔐 ارتباط امن و مستقیم بدون نیاز به سرور مرکزی
- ⚡ کیفیت بالا و تأخیر بسیار کم در انتقال تصویر
- 🧑‍💼 محیط مدیریت کارگردان با قابلیت چت گروهی
- 📱 امکان استفاده از دوربین گوشی به‌عنوان وب‌کم بی‌سیم
- 🌐 پشتیبانی از استانداردهای WHIP/WHEP و قابلیت استقرار سرورهای SFU اختصاصی

## 🛠️ استقرار و شخصی‌سازی

تمام کدهای این پروژه روی GitHub Pages قابل اجرا هستند و می‌توانید بدون نیاز به سرور، آن را به‌سادگی روی دامنه دلخواه خود استقرار دهید. این نسخه در دامنه `remotevm.site` به‌صورت بهینه و سفارشی‌شده میزبانی می‌شود.

در صورت نیاز به نسخه‌ای خصوصی، قابلیت استقرار کامل روی سرور شخصی با امکاناتی مانند TURN، STUN، و WHIP/WHEP فراهم است.
